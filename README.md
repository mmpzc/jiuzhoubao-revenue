# 九州堡营收管家

手机端营收记录页面，适合汉堡店每日记账使用。

## 已实现功能

- 四个营收渠道：小程序、卡机、淘宝闪购、美团
- 每个渠道可分别设置扣点比例和每日固定扣费
- 淘宝闪购、美团可每日单独记录推广费
- 每日自动扣除房租、人工、水电和其他经营费用
- 自动计算营业额、平台到账、经营净利、净利率
- 历史记录按月汇总，支持点击回到当天修改
- 历史记录锁定保存时的扣点，之后修改设置不会改算旧账
- 一键复制经营日报
- 全量 JSON 备份恢复、CSV 明细导出
- 可安装到手机桌面，支持离线打开
- 数据只保存在本机浏览器，不上传服务器

## 首次使用

1. 打开页面进入“设置”。
2. 按平台后台或合同填写四个渠道的扣点和每日固定扣费。
3. 填写每日房租、人工、水电、其他费用的默认金额。
4. 回到“记账”，填写当天各渠道营业额和推广费后保存。

## 部署成永久网址

推荐使用 Netlify Drop：

1. 打开 https://app.netlify.com/drop
2. 登录免费账号。
3. 将本文件夹或 `九州堡营收管家-部署包.zip` 拖入页面。
4. 部署完成后会得到 `https://xxxx.netlify.app` 永久网址。
5. 在 Netlify 后台可修改站点名称，也可绑定自己的域名。

其他可用方式：GitHub Pages、Cloudflare Pages、Vercel。由于应用是纯静态页面，以上平台均可免费托管。

## 数据说明

- 页面不包含云端数据库，营业额不会上传到服务器。
- 数据保存在当前手机浏览器中；换设备或换浏览器不会自动同步。
- 清理浏览器数据、卸载浏览器前，请先在“设置 → 数据备份”导出 JSON。
- 若以后需要多台手机实时同步，需要另接云端数据库（如 Supabase）。
